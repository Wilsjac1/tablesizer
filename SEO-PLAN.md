## Content roadmap (next 5 guides, in order)
1. **Conference table for 12 / 14 / 16 people** — seat-count landing pages from the size chart (feeds planner presets).
2. **Round conference table sizes** — diameter chart (4–12 people) using the round rule.
3. **U-shaped conference room layout** — seats-per-foot for training/video rooms, display wall guidance.
4. **Conference table height & chair clearance** — 29–30″ height, knee space, chair arm clearance.
5. **Boat-shaped conference table guide** — sightlines, widths, when to choose boat vs rectangle.

Each guide: one H1, sourced rules, a chart generated from `calc.js` (never hand-typed numbers), FAQ + breadcrumbs, and a planner deep-link with the size pre-filled.
