Conference table dimensions

Most conference tables are 29–30 in high, 36–60 in wide, and 6–24 ft long. Width grows with length so people at the far end can still see and reach the center.

Height

Standard table height is 29–30 in, paired with standard office chairs. Standing-height tables run about 40–42 in.

How the numbers work

Allow 30 in of edge per person (36 in to be comfortable), one person at each end, and 42–48 in from the table edge to the wall. See the methodology or use the calculator.
